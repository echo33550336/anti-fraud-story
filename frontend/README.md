# 《终场前的一张票》前端源码

## 运行

解压后保持目录结构，打开 `index.html` 即可预览。接 API 时建议在此目录运行 `python -m http.server 8080`，访问 `http://localhost:8080/`。无需构建工具。

## 包内文件

- `index.html`：页面结构。
- `src/styles.css`：界面样式与响应式布局。
- `src/story.js`：美工资源映射、15 节点剧情、16 个结局文案。
- `src/game.js`：状态、选择/自由回答、路由、结算和 UI 更新。
- `examples/backend-adapter.example.js`：HTTP 对接示例，默认不加载，需按实际 API 修改。
- `美工/`：该 HTML 实际引用的 15 张 JPEG。其他未引用的设定卡、UI 参考图、视频没有放入包内。
- `终场前的一张票_15节点16结局.md`：本版剧情来源，供核对文案与结果。
- `接口对齐.md`：当前页面已有的后端接入点、数据样例与待统一事项。

## 如何编辑

- 改剧情、选项或结局：编辑 `src/story.js` 中的 `S`、`E`。
- 改画面：编辑 `src/styles.css`；图片地址在 `src/story.js` 的 `assets`。
- 改推进、评分、徽章：编辑 `src/game.js`。
- 接后端：实现 `window.evaluateFreeAnswer`；监听 `game:ended` 并调用 `window.setGameResult`。详见 `接口对齐.md`。

## 版本提醒

工作区中的 `反诈陪练-demo-backend/` 仍基于旧版《终场前的两张票》，其开放题为 N12–N14，与本包不兼容。本包以最新单张票剧情为准：**N03、N15 为自由回答，其余 13 个节点仅有固定选项**。

## 当前能力边界

前端目前是可离线运行的演示版。未接入真实 Agent 或后端服务；自由回答默认由本地关键词规则路由，评分与徽章默认由本地演示函数生成。接入后端后，应由后端给出权威评分、徽章和复盘，同时校验玩家实际路径。
