# 一张票，两张脸 · JavaScript 前端

这是新的前端源码工程。页面结构由 `src/ui.js` 生成；`index.html` 仅是约 250 字节的浏览器启动壳。无框架、无第三方依赖，Node.js 18+ 可运行开发服务器和同源 API 代理。

## 启动

```bash
cd frontend-js
node server.mjs
```

有 npm 的环境也可使用 `npm run dev`；运行测试用 `node --test`。

打开 `http://127.0.0.1:8080/`。默认是**后端模式**，请求同源 `/api/story/*`。`server.mjs` 把 `/api/*` 代理到 `API_UPSTREAM`，默认 `http://127.0.0.1:5000`，从而避免前后端跨域。部署时配置 `HOST`、`PORT`、`API_UPSTREAM`。若部署平台已有同源反代，也可直接把目录作为静态站点发布。

访问 `http://127.0.0.1:8080/?mode=demo` 可运行**本地演示模式**；该模式的关键词意图、评分、徽章均为演示实现，不代表 Agent。后端模式请求失败时，封面会提供“改用演示模式”按钮，不会悄悄降级。

## 后端对接状态

前端已具备真实 HTTP 请求、`session_id`、稳定 `option_id`、自由回答确认、结局 review 和错误状态。**现有 `反诈陪练-demo-backend/` 仍是另一套剧情模型，不能直接驱动此页面。** 前端在 `/start` 检查 `story_id: "one-ticket-v1"`，旧后端缺少此版本号时会明确报错。后端同学需按 [API_CONTRACT.md](API_CONTRACT.md) 实现单张票图剧情，或双方先确定另一套权威剧情后再改前端。不会做 E/R 结局的伪映射。

## 配音与素材

序章按 `P01`–`P25` 尝试播放 MP3；缺少时显示“配音待导入”，按阅读时间推进。当前票据使用已有图片；工牌、便签、现金、同事采用文字特写卡。现有角色 JPEG 含背景，采用卡片式立绘；真正透明立绘需另提供 PNG/WebP。
## 分镜推进（15 幕）

一幕一节点：序章 25 句 + 15 幕共 169 句。进入节点先逐句出词，读完才出现选项。

| 幕 | 节点 | 句数 | 幕 | 节点 | 句数 |
|---|---|---|---|---|---|
| 1 走出剧院 | N01 | 8 | 9 128 元山货 | N09 | 10 |
| 2 陌生来电 | N02 | 17 | 10 真货到了 | N10 | 10 |
| 3 主动核实 | N03 | 8 | 11 信任升级 | N11 | 13 |
| 4 看起来很正规 | N04 | 8 | 12 3000 元投资 | N12 | 12 |
| 5 第一次转账 | N05 | 8 | 13 追加费用 | N13 | 13 |
| 6 连环转账 | N06 | 14 | 14 最后一次付款 | N14 | 12 |
| 7 对方失联 | N07 | 10 | 15 终场前的核实 | N15 | 14 |
| 8 熟悉的头像 | N08 | 12 | | | |

结算页另有 **16 个结局 × 3 句**收尾分镜（`ENDING_BEATS`），在概述之前逐句浮现。

- 每句：`{ who, text, phone? }`；`who` 决定说话人和角色聚焦，`phone` 把一行追加进右侧虚拟手机。第 8–14 幕的“ 小岚 ”显示为**未核实账号**，不会冒用真实小岚的立绘。
- 交互：`继续 ▸` 逐句、`全部展开` 直接显示最后两句、点对白区或按空格/回车推进；最后一句按钮变为 `做出选择 ▸`。对白区始终保留当前句与上一句。
- 体例对齐《第一幕大剧院版·整合稿》：第三人称旁白写可见动作，不写括号心声，不自行增删情节。
## 配音：非主角自动播放

- **主角（林夏，6 句）不配音、不自动播放**；其余 **163 句**（旁白 120 / 小岚 25 / 票务部 17 / 剧院总机 1）在出场时自动播放 `public/voice/story/{节点}_{行号}.mp3`。
- 文件缺失自动回落浏览器 TTS；实际音色取决于访问者设备安装的中文语音。
- 顶部有 `语音：开 / 关` 开关；点 `全部展开` 时不逐句读，只读最后一句，避免音频排队。
- 音色（edge-tts 神经语音）：旁白 云健 `YunjianNeural`、小岚 晓晓 `XiaoxiaoNeural`、票务部 云扬 `YunyangNeural`（播音腔）、总机 晓伊 `XiaoyiNeural`。
- 清单：`contract/lines.json`（机器可读）、`contract/lines.md`（按幕 + 按角色索引）。
- 本轮分镜修订改变了 29 句旁白。旧 MP3 已移至 `public/voice/stale-after-review/`，防止出现文字与声音不一致；`contract/lines.json` 的 `audio_ready` 标明每句是否有可用 MP3。补录前这 29 句会使用浏览器语音。
- 重生成：

```bash
node tools/export-lines.mjs        # 改台词后先导出清单
python tools/gen-story-voice.py    # 只补缺失；--force 全量重生成
```

## 背景音乐：一幕一曲

15 幕各有一段氛围 BGM，切幕时自动交叉淡入淡出；**说话时自动压低**（duck 到 16%），说完恢复。

| 幕 | 情绪 | 幕 | 情绪 |
|---|---|---|---|
| 1 走出剧院 | 暖·期待 | 9 128 元山货 | 人情味 |
| 2 陌生来电 | 暗流 | 10 真货到了 | 松弛 |
| 3 主动核实 | 清醒 | 11 信任升级 | 铺陈 |
| 4 看起来很正规 | 假体面 | 12 3000 元投资 | 压 |
| 5 第一次转账 | 不安 | 13 追加费用 | 重复下坠 |
| 6 连环转账 | 加速 | 14 最后一次付款 | 顶点 |
| 7 对方失联 | 空洞 | 15 终场前的核实 | 落定 |
| 8 熟悉的头像 | 温柔的假象 | | |

- 音轨：`public/voice/bgm/act01.mp3` … `act15.mp3`，15 段共 1.63 MB，约 11–18 秒无缝循环。
- 生成方式：`python tools/gen-bgm.py`，**程序化合成**（加法合成：低频铺底 + 和弦垫 + 琶音 + 空气噪声 → 软限幅 → mp3），无版权素材。
- 响度已统一到同一 RMS（0.085），切幕不会忽大忽小；频谱重心 447–1369 Hz，暗幕（5/7）明显比暖幕（1/8）暗。
- 顶部有 `音乐：开 / 关` 开关；首次点「进入故事」时才解锁播放（浏览器要求用户手势）。

## 动效系统（v3 新增）

只做表现层，**不改任何剧情、评分、跳转逻辑**。

| 效果 | 位置 | 说明 |
|---|---|---|
| 屏幕入场 | 封面→序章→剧情→结算 | 淡入 + 上移 10px，`screen-enter` 类每次重播 |
| 换幕黑场卡 | 每次换幕 | 黑底 + 「第 0X 幕」+ 幕名，760ms 后自动淡出 |
| 选项逐个弹入 | 选项区 | 每项延迟 70ms（`--i` 变量阶梯） |
| 手机消息弹入 | 虚拟手机 | 每条消息 240ms 上浮淡入 |
| 台词分级 | 对白区 | 旁白灰白偏小；角色台词加左侧色条（小岚粉 / 票务紫 / 总机青） |
| 叙事区遮罩 | 对白区 | 顶部渐隐，暗示可回看 |
| 背景缓推 | 全站 | 34 秒极缓推近（移动端 48 秒） |
| 结算分数滚动 | 结算页 | 0 → 目标值 700ms 缓出 |

**开关**

- 顶栏 `动效：开 / 关` 一键切换（`html.no-motion` 下所有动画/过渡压到 0.001ms）
- 跟随系统 `prefers-reduced-motion: reduce`
