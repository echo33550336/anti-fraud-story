# 部署与公网演示（三条路线，按"最快能拿到链接"排序）

> 手册要求：Agent 赛道建议提供**可直接访问的 Demo 链接**，同时准备**本地备份**。
> 当前 `backend/app.py` 同时托管 `frontend/`：启动后访问根路径 `/` 就是完整游戏，`/api/story/*` 是接口。**一个进程、一个链接，不需要再单独起前端**。

---

## 路线 A：2 分钟拿到公网链接（推荐，无服务器）

在**本机**保持 demo 运行时，另开一个 PowerShell 窗口，把本地 5000 端口暴露成公网地址。

### A-1 用 Windows 自带 OpenSSH（不用装任何东西）

```powershell
ssh -o StrictHostKeyChecking=no -R 80:localhost:5000 nokey@localhost.run
```

命令跑起来后会打印公网服务地址，打开根路径就是游戏页面。

- 优点：零安装、1 分钟搞定
- 缺点：链接是临时的（进程关掉就失效），偶尔延迟高；**演示当天再准备一次**即可
- 若提示 `ssh 不是内部或外部命令`：设置 → 应用 → 可选功能 → 添加「OpenSSH 客户端」

### A-2 用 cloudflared（更稳，需一次安装）

```powershell
winget install --id Cloudflare.cloudflared
cloudflared tunnel --url http://127.0.0.1:5000
```

打印出的 `https://xxx.trycloudflare.com` 即公网链接。工作区已下载绿色版时可直接运行：

```powershell
.\_incoming\cloudflared.exe tunnel --url http://127.0.0.1:5000
```

### A-3 localtunnel（有 Node 时）

```powershell
npx localtunnel --port 5000
```

> ⚠️ 三条隧道都要求**本机 demo 正在运行**、电脑不休眠、网络不断。评委扫码时若打不开，立刻切到"本机演示 + 录屏视频"。

## 路线 B：Render 免费部署（长期链接，20 分钟）

仓库根目录已经准备好 `Dockerfile` 和 `render.yaml`（同时包含前后端）：

1. 把仓库推到 GitHub / AtomGit。
2. 打开 https://render.com → New → Blueprint（或 Web Service），连接仓库。
3. Render 会自动识别根目录的 `render.yaml`，用 Docker 构建；不需要 pip install。
4. 部署完成得到 `https://xxx.onrender.com`，根路径直接打开游戏。

> 免费实例会休眠：**演示前 2 分钟先访问一次预热**，否则评委第一次打开要等 30 秒。
> 关键环境变量：`HOST=0.0.0.0`、`ALLOW_PUBLIC=1`；端口用 Render 注入的 `PORT`。

## 路线 C：Docker（有服务器时）

在**仓库根目录**构建（Dockerfile 会一并复制 `backend/` 和 `frontend/`）：

```bash
docker build -t anti-fraud-story .
docker run -p 8000:8000 -e HOST=0.0.0.0 -e PORT=8000 anti-fraud-story
```

打开 http://localhost:8000

## 部署后必做的 3 个自检

1. `GET https://你的域名/api/health` → 应返回 `{"ok": true, "service": "story-agent"}`
2. `GET https://你的域名/` → 应返回《终场前的一张票》游戏首页（HTML）
3. `POST https://你的域名/api/story/start`，发送空 JSON 对象 `{}` → 应返回 `session_id`、首个 `node` 和 `progress`；再点两次选项能正常推进

## 安全与合规（公开链接前必看）

- 当前服务不调用外部模型接口，也不读取 DeepSeek 密钥；部署时无需配置模型 Key。
- 服务端**不存储**用户消息（当前实现只在内存中处理，不写库、不落盘日志内容），可在答辩时主动说明。
- 设置 `HOST=0.0.0.0` 时 Host 校验会放开；本地默认 `HOST=127.0.0.1`。
- 要限制为本机访问，设置 `HOST=127.0.0.1` 并停止隧道或公网端口映射。`ALLOW_PUBLIC=0` 不会覆盖 `HOST=0.0.0.0`。
