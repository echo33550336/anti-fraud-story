# 当前实施状态

## 目标

实现《终场前的两张票》15 步确定性剧情 agent，覆盖七维评分、16 个结局、徽章、开放回答映射和完整复盘。

## 事实与评分边界

- 剧情事实来自配置；模型不能补造决定性证据或更改已发生的选择。
- 开放回答只映射到当前节点的固定选项；玩家确认后才影响状态。
- 七维评分由已记录选择计算；恋爱回应不改变安全等级。
- 最终分将原始 0–100 分映射为 50–100 的整数分。
- 复盘应展示选择依据和各维度，不把总分解释为人格或现实风险概率。
